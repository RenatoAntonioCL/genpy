# ADR-0010: Internationalization English + Spanish (D1)

- **Status:** Accepted
- **Source:** `CONTEXT.md` → "Closed Decisions" (D1)

## Context

GenPy targets Spanish- and English-speaking users. The interface needs translatable
text without scattering string literals throughout the code.

## Decision

**i18n with English + Spanish from v1**, centralized in `lib/i18n/` (`en.sh`, `es.sh`).

## Consequences

- (+) Consistent messages and a single place to translate.
- (+) Adding a new language means adding one file, without touching the logic.
- (−) Every visible string must go through the i18n layer (permanent discipline).
