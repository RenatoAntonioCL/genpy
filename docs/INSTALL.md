# Instalación

## Requisitos

- Bash 4.3+
- Git
- Docker (para blueprints con contenedores)
- macOS, Linux o WSL2

## Desde el repositorio

```bash
git clone https://github.com/RenatoAntonioCL/genpy.git
cd genpy
bash scripts/install.sh
```

## Comandos

```bash
genpy create
genpy version
genpy update
genpy uninstall
```
