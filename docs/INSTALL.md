# Installation

## Requirements

- Bash 4.3+
- Git
- Docker (for blueprints with containers)
- macOS, Linux or WSL2

## From the repository

```bash
git clone https://github.com/RenatoAntonioCL/genpy.git
cd genpy
bash scripts/install.sh
```

## Commands

```bash
genpy create
genpy version
genpy update
genpy uninstall
```
